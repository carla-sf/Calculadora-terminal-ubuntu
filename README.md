# Calculadora-terminal-ubuntu
 Calculadora em Python
 Este é um projeto simples de calculadora desenvolvido em Python.  
O usuário informa dois números e escolhe a operação desejada: soma, subtração, multiplicação ou divisão.

No terminal, rode:
```bash
python3 calculadora.py

Dê permissão de execução

chmod +x run.sh

Depois, rode:

./run.sh
